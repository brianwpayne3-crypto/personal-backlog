# Project / Idea Index

_Last reviewed: 2026-08-23_

This is the lightweight catalog above the detailed GitHub backlogs. GitHub issues and project repos remain the source of truth for implementation detail, decisions, and history. This file captures the essence, current state, and story value of the work so it can be scanned quickly and reused for LinkedIn, consulting/marketing, portfolio material, interviews, or deciding what to work on next.

## State vocabulary

- **Idea** — captured, but not actively explored.
- **Exploring** — concept/research/design is being developed.
- **Building** — implementation is actively underway.
- **Live** — being used in the real world or deployed for its intended purpose.
- **Paused** — intentionally not active right now.
- **Archived** — no longer active / superseded.

State is deliberately separate from **Stage**, which describes how far the work has actually progressed.

## How to use this file

Examples of useful scans:

- **Planning:** What is Building right now? What has been Exploring too long? What should remain parked?
- **LinkedIn:** Which projects contain a specific observation or lesson worth expressing in Brian's own voice?
- **Consulting site:** Which projects best demonstrate discovery, operational redesign, buy-vs-build judgment, integration, and measurable real-world use?
- **Interview prep:** Which projects demonstrate technical leadership, product judgment, systems thinking, operator empathy, or agentic-development fluency?
- **Portfolio:** Which items have enough real artifacts/evidence to show rather than merely describe?

## Maintenance rule

Do **not** turn this into another detailed backlog. Detailed work stays in the project repositories/issues. Update this index only when a project's essence, state, stage, next meaningful step, or story materially changes.
